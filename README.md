# Hello REST API Messaging App

This project demonstrates a simple **Spring Boot REST API application** that handles different HTTP request methods.  
The application provides various endpoints to return greeting messages using query parameters, path variables, request bodies, and different HTTP methods.

---

## Technologies Used

- Java
- Spring Boot
- Maven
- IntelliJ IDEA
- REST API
- CURL

**User Case Description

UC1: Returns a simple greeting message “Hello from BridgeLabz” using a GET request.

UC2: Returns a greeting message by accepting a name as a query parameter in the URL.

UC3: Returns a greeting message by accepting a name as a path variable in the endpoint.

UC4: Accepts first name and last name in JSON request body using a POST request and returns a greeting message.

UC5: Accepts first name as path variable and last name as query parameter using a PUT request and returns a greeting message.
